ログインは世界へ入るための扉です。作品ごとに同じ手続きを何度も繰り返すものであってほしくありません。

そのために作ったのが Hoshi ID です。ひとつのアカウントセンターで、次のことができます。

- **一度の登録で**：同じアカウントから Hoshivel の作品にログインできます
- **まとめて管理**：プロフィール、ログイン履歴、連携中のサービスを確認できます
- **アカウントを守る**：パスワードとログイン状況を一か所から管理できます
- **データを分けて保管**：アカウント情報は Hoshi ID が、ゲームデータは各作品がそれぞれ保管します

『砕界』は、Hoshi ID に対応した最初の作品です。ゲーム内で「Hoshi ID でログイン」を選ぶと、ゲームのプロフィールが自動で作成または読み込まれます。

これから生まれる Hoshivel の作品も順次対応し、同じアカウントから、さらに多くの世界へ進めるようになります。
