我們希望登入只是通往世界的一扇門，而不是進入每部作品前都要重走一遍的手續。

因此，我們建立了 Hoshi ID。你可以在同一個帳戶中心完成這些事：

- **一次註冊**：使用同一個帳號登入 Hoshivel 的作品
- **集中管理**：查看個人檔案、登入紀錄與已連結的服務
- **帳號安全**：在同一處管理 passkey、登入方式與登入中的裝置
- **資料分開管理**：帳號資料由 Hoshi ID 保管，各作品只儲存自己的遊戲資料

《碎界 Shattered Realms》是第一款支援 Hoshi ID 的作品。在遊戲中選擇「使用 Hoshi ID 登入」，即可建立或載入遊戲檔案。

未來的 Hoshivel 作品也會陸續支援 Hoshi ID，讓同一個帳號陪你走進更多世界。
