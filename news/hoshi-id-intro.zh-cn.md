Hoshi ID——Hoshivel 的通用账号与 OpenID Connect 身份服务——正式上线。

我们希望玩家在 Hoshivel 的世界里只需要记得一件事：自己是谁。其余的——登录、会话、与各作品的连接——都交给账户中心集中管理：

- **单一账号、单点登录**：以 OAuth 2.0 ＋ OpenID Connect 标准打造，一次注册，通行全部作品；
- **账户中心**：个人资料、安全会话、已连接服务与登录记录，一页看清、随时撤销；
- **安全为先**：短效凭证、Refresh Token 轮替与重用检测；密码重置会登出所有会话；
- **数据各归其位**：各作品只保存自己的游戏数据，邮箱与密码由 Hoshi ID 保管。

《碎界 Shattered Realms》已率先接入——从游戏点「使用 Hoshi ID 登录」，即可自动创建或加载你的游戏档案。

之后的每一件 Hoshivel 作品，都会经由同一个 Hoshi ID 与你见面。
